**Vice Panels** — an offline cover-art maker that cuts your own photos into a GTA-style multi-panel poster: four panel layouts (mosaic grid, hero & strips, slanted columns, wide duo), per-panel crop and zoom (drag to reframe, scroll to zoom), Vice City colour grades (Vice Sunset, Neon Nights, Golden Hour), and bold poster lettering set in Anton (SIL Open Font License, bundled in `app/fonts/`). One photo can fill a single panel or stretch across all of them. Export a finished cover as a PNG at 1080×1080, 1080×1350 or 1920×1080. Pure static files — no build step, no network requests, and your photos never leave your machine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

To hand the entry in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
